# Mach — Projection Logic + Fundraising Plan

**Two things: (1) the *logic* behind the projections so they hold up to a VC's questions, and (2) the rounds you should raise, when, how much, and at what valuation.**

> These are a planning model with explicit assumptions, not a promise. The point is a *defensible* curve a VC can interrogate — built bottom-up from one driver, not a hockey stick pulled from the air.

---

## 1. The projection logic (one driver, compounding)

Don't project revenue directly — project the **one thing that creates it: active earning agents.** Everything else is arithmetic off that.

**The core identity:**
> **Mach revenue = (active earning agents) × (avg agent earnings) × (Mach take rate)**

**The locked assumptions (state these on the slide):**
- **Avg agent GMV:** ~$1,200/month (blended — top agents far more, long tail less). Grounded vs the Aisha $15K/mo hero case; deliberately moderate.
- **Mach take rate:** 17% (platform fee + marketplace + campaign fees).
- → **Mach revenue per active agent ≈ $204/month ≈ $2,400/year.**
- **Content cost reality:** ~$4/video; an agent posting daily costs ~$120/mo and breaks even at ~40K views/mo — so agents **self-sustain after a short ramp**, which is why the base compounds instead of bleeding.

**Why the curve compounds (the part that makes it believable):**
1. **Self-distribution** — every video an agent posts advertises Mach, so customer-acquisition cost falls as the base grows.
2. **The asset compounds** — agents accumulate audience + memory + reputation, so older agents earn more and churn less.
3. **Operators multiply** — one operator runs 1 → 10 → 50 agents, so agent count grows faster than user count.
4. **The market is pulling** — AI-influencer demand is growing ~41%/yr with budgets actively reallocating, so you're swimming downstream.

The projection is just: *how fast does active-agent count climb, multiplied by $2,400.*

## 2. The 4-year base-case projection

| | End Y1 | End Y2 | End Y3 | End Y4 |
|---|---|---|---|---|
| **Active earning agents** | 3,000 | 18,000 | 70,000 | 180,000 |
| **Agent GMV (annualized run-rate)** | $43M | $260M | $1.0B | $2.6B |
| **Mach revenue (exit ARR run-rate)** | **~$7M** | **~$43M** | **~$168M** | **~$432M** |
| Realized revenue in-year (~55% of exit) | ~$3M | ~$22M | ~$95M | ~$250M |
| Team size | 6–8 | 18–25 | 50–70 | 120+ |
| Rough annual burn | $1–1.5M | $6–10M | $30–45M | profitable-ish / reinvesting |

> "Exit ARR run-rate" = the December run-rate VCs price off. Realized in-year revenue is lower because you're growing into it — always show both so the model looks honest.

**Three scenarios (at the End-Y3 checkpoint):**

| Scenario | Active agents | Avg GMV/mo | Take | Mach exit ARR |
|---|---|---|---|---|
| Conservative | 40,000 | $800 | 15% | **~$58M** |
| Base | 70,000 | $1,200 | 17% | **~$168M** |
| Bull | 110,000 | $1,800 | 20% | **~$475M** |

Even the **conservative** case is a $50M+ ARR company by Year 3 — a clear venture outcome. That asymmetry (floor is still big) is exactly what a VC wants to see.

## 3. The fundraising plan — rounds, timing, amounts

Raise on **milestones, not time.** Each round buys ~18–24 months of runway to prove the *next* milestone that unlocks the *next* round at a step-up valuation. Stack non-dilutive grants underneath everything to extend runway and cut dilution.

| Round | When | The milestone that unlocks it | Raise | Post-money (range) | Dilution | Primary use of funds |
|---|---|---|---|---|---|---|
| **Grants** (non-dilutive) | Now → ongoing | Solana Foundation, Superteam SEA, regional AI/startup grants | **$50K–250K** | — | 0% | Extend runway, fund build, on-chain infra |
| **Pre-seed** | Now | Working builder + marketplace; first agents earning real money | **$0.75M–1.5M** | **$6M–10M** | ~12–15% | MVP→v1, first ~3K agents, 2 case studies |
| **Seed** | ~12 mo | ~$5–7M exit ARR; retention + marketplace liquidity proven | **$3M–5M** | **$20M–35M** | ~15–20% | Growth engine, team to ~20, agent supply + demand |
| **Series A** | ~24 mo | ~$40M+ ARR; clear PMF; repeatable acquisition | **$15M–25M** | **$80M–150M** | ~18–20% | Scale agents, geo expansion (SEA→global), infra/reliability |
| **Series B** | ~36 mo | ~$150M+ ARR; category leadership | **$40M–70M** | **$400M–800M** | ~12–15% | Dominance, enterprise, M&A, (token decision if it fits) |

**The logic of the amounts:** each raise ≈ the burn needed to reach the next milestone + a buffer. You're not raising the most you can — you're raising enough to clearly clear the next bar, so the following round is an obvious up-round.

**If you want a leaner path (less dilution):** skip a formal pre-seed, lean on grants + a slightly larger seed once you have first revenue. If you want to move fast in a hot market: take the top of each range. Given you're applying for grants and SEA-based, I'd run **grants + a $1M pre-seed now**, then a **$3–5M seed** off first traction — that keeps founder ownership healthy into Series A.

## 4. How the raise maps to the projection (the story a VC hears)

- **Pre-seed ($1M):** "We've built the builder + marketplace and the first agents are earning. Fund us to get to 3,000 agents and ~$7M run-rate." → de-risks *product*.
- **Seed ($3–5M):** "Agents earn and retain; the marketplace clears. Fund the growth engine to ~$43M ARR." → de-risks *go-to-market*.
- **Series A ($15–25M):** "Acquisition is repeatable and the unit economics work. Fund scale to ~$168M ARR and global expansion." → de-risks *scale*.
- **Series B ($40–70M):** "We're the category leader. Fund dominance." → de-risks *moat/defense*.

Each step pairs a **proof** with a **use of funds** and a **valuation step-up** — that's the entire fundraising narrative.

---

## 5. Founder ownership sanity check (rough)

Across grants + pre-seed (~13%) + seed (~18%) + Series A (~19%) + option pools, founders typically retain roughly **45–55%** going into Series B if rounds are run cleanly and grants offset early dilution. The non-dilutive grant stack is the lever that keeps this healthy — lean on it hard early.

---

## 6. Honest caveats (so the model survives diligence)

- The whole curve hinges on **active, earning, retained** agents — not sign-ups. Activation/retention is the real risk; instrument it from day one.
- Per-agent earnings are a power law; the $1,200 blended average already bakes in a long tail — don't let anyone read it as "every agent makes $1,200."
- Video-gen cost ($4/video) and platform AI-labeling/ToS rules are live variables — a cost drop helps margins, a policy change can hurt reach. Monitor both.
- Valuation ranges assume the AI-creator category stays hot (it's at ~41% CAGR now). Multiples compress if sentiment cools — which is why **real revenue** (not the speculative invest feature) is the right thing to build.
